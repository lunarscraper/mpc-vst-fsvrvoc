## What is in this repository and where it came from

**Our own work, GPL-3:** everything in `src/`, `plugin/`, `hollow/`, `tools/` and `docs/` except the files listed below. The engine is a clean rewrite in C++ of what the FS1R's CPU does between MIDI and the tone generator registers, worked out by reading the v1.20 firmware. It contains no Yamaha code. `hollow/` is the plug-in framework the editor runs on, written for this project and its sibling products.

**Extracted from Yamaha's EPROM, not ours to license:**

- `src/fs1r/firmware/tables.h` - the CPU-side conversion tables (velocity curves, level scaling, the note table, the pan tables and the rest), generated by `tools/extract_tables.py` from a v1.20 EPROM image.
- `src/fs1r/firmware/algorithms.h` - the 88 algorithm words.
- `presets/` - the 1408 preset voices, the 384 preset performances and the 90 preset formant sequences, as `.syx` files and an index, generated by `tools/extract_presets.py`, and the same data packed into `plugin/generated/fs1r_presets.syx`, `fs1r_presets.csv`, `fs1r_performances.syx` and `fs1r_fseqs.syx` by `tools/make_presets_blob.py` so the plugin can load them with no EPROM image present.
- `docs/vop3_microcode.md` and `docs/vop3/` - VOP3-1's program and coefficient tables, the YSS236 that runs the per-voice filter, generated by `tools/extract_vop3.py`. Reference material; nothing here depends on it.

These are Yamaha's data. They are included because the emulation is worthless without the exact tables, and because the tools that regenerate them from an EPROM image are in the repository. If you object to their presence, the generators reproduce every one of them from a dump you make yourself.

**Not in this repository:** the FS1R firmware, the EPROM image and the SH7044 flash. You need your own dump to use `-r` or `tools/extract_*.py`.

**Documentation quoted from:** the FS1R owner's manual and Data List (Yamaha, 1998) and US patent 5,610,354. The text files under `docs/` are conversions kept for reference while working; the parameter tables in `plugin/generated/parameterDescriptions_fs1r.json` are derived from them. `src/fsvr/display.h` is transcribed from K_Take's freeware FS1R Editor, with credit in the file.

**The editor** features aspects under their own licences: glyphs of the [Saira](https://fonts.google.com/specimen/Saira) typeface (SIL Open Font License 1.1) and icons from Google's [Material Symbols](https://fonts.google.com/icons) (Apache License 2.0). The layouts in `plugin/skin/views` and the tables in `plugin/skin/data` are this project's.

**In `hollow/third_party/`, under their own licences:** `stb/` (stb_image and stb_image_write, public domain or MIT), `strmbase/` (Microsoft's DirectShow BaseClasses, MIT, for the DXi), and `vst2/`, a minimal VST 2.4 ABI header written for this project from the public interface description.

**Downloaded by the plug-in build, not redistributed here:** the CLAP SDK and [clap-wrapper](https://github.com/free-audio/clap-wrapper) (MIT), which fetches Steinberg's VST3 SDK (GPL-3 or proprietary), Apple's AudioUnitSDK (Apache License 2.0), RtAudio and RtMidi (MIT-style); and Import Audio's decoders, [dr_libs](https://github.com/mackron/dr_libs) (dr_wav and dr_mp3) and [stb_vorbis](https://github.com/nothings/stb), both public domain or MIT No Attribution. Release binaries contain them.

**Import Audio's method** follows [fseq-flash](https://github.com/zkarcher/fseq-flash) by Zach Archer (MIT): its pitch detector, spectral analysis and formant picking, rewritten here in C++ with the engine's own byte scales.
